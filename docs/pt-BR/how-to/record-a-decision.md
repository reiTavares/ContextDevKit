# Registrar uma decisão

Crie ADR quando uma escolha material precisa sobreviver à sessão e orientar trabalho futuro.

## Crie ADR para

- mudança de contrato público;
- nova autoridade de estado;
- alteração de boundary de domínio;
- migração/cutover relevante;
- adoção de dependência estratégica;
- trade-off arquitetural com consequências duráveis.

Não crie ADR para cada detalhe de implementação.

## Conteúdo mínimo

- contexto/problema;
- decisão;
- alternativas relevantes;
- consequências/trade-offs;
- status e links para Business/Operation/Workflow quando aplicável.

Deliberação/council pode fornecer perspectivas, mas não autoriza a decisão. O ADR é memória do racional aceito.

Depois de registrar, atualize referências do Workflow/Business/Operation quando necessário e regenere índices derivados.
