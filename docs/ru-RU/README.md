# Документация ContextDevKit — Русский

Локаль: `ru-RU` · направление текста: `ltr`

Эта папка является официальным пространством русской документации ContextDevKit.
Английская документация в `docs/` остаётся каноническим источником технического контракта, пока перевод конкретной страницы не отмечен как актуальный.

## Статус

Русская локализация подготовлена к поэтапному заполнению. Структура должна зеркально повторять английскую документацию: `tutorials/`, `how-to/`, `reference/`, `explanation/` и `workflow-engine/`.

- Каноническая документация: [English](../README.md)
- Português (Brasil): [pt-BR](../pt-BR/README.md)
